# Changelog

## 1.0.1 — 2026-11-13

- 为 V1 上传补齐旧快照覆盖保护，并返回 HTTP 409。
- 将分块预算下限统一为 256 KiB，修复 HTTP 413 后继续缩块失败。
- 上传连接提前重置时有界缩块重试，保留快照幂等提交。
- CLI 启动失败时说明命令、错误码及恢复配置项，避免重复日志。
- 页面网络失败时给出中文恢复提示。
- 补充上述问题的单元与 PostgreSQL 集成回归。

## 1.0.0 — 2026-11-12

- 提取 Multica 费用分析、模型价格版本和汇率管理。
- 提供独立 PostgreSQL 服务、回环监听、管理员登录和 HMAC 采集入口。
- 支持全 Workspace V2 快照、原子分块提交、失败范围保护和重复上传。
- 提供服务器及电脑安装、SSH 访问和调度说明。
